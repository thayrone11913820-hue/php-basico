# PHP Básico

Atividades práticas de Programação Web I (Técnico em Informática).

**Aluno:** Substitua pelo seu nome.

## Projetos

- `01-hello-world`: primeira página em PHP.
- `02-data-hora`: data, hora e saudação conforme o horário.
- `03-imc`: cálculo e classificação educativa de IMC para adultos.
- `04-produtos`: lista de produtos com array associativo.

## Como executar

1. Instale e abra o Laragon.
2. Inicie os serviços pelo botão **Start All**.
3. Coloque esta pasta em `C:\\laragon\\www\\php-basico`.
4. Abra no navegador:
   - `http://localhost/php-basico/01-hello-world/`
   - `http://localhost/php-basico/02-data-hora/`
   - `http://localhost/php-basico/03-imc/`
   - `http://localhost/php-basico/04-produtos/`

## O que aprendi

- Criar páginas usando PHP junto com HTML.
- Utilizar variáveis, `echo` e funções.
- Trabalhar com data, hora e estruturas condicionais.
- Criar arrays associativos e percorrê-los com `foreach`.
- Registrar as etapas do projeto usando Git.

## Soluções alternativas que testei

- Usei `<?= $variavel ?>` para exibir valores dentro do HTML.
- Usei concatenação com o operador `.` para montar uma mensagem.
- Usei `elseif` para classificar os valores em faixas.
- Usei `foreach` para percorrer a lista de produtos.
